## 2. Cross-model review orchestrator (cross-model-review)

- [ ] 2.1 Author `.claude/commands/xtty/cross-review.md` as the **main-loop protocol**: given an in-scope change, launch **Pass B** (`codex-companion.mjs adversarial-review`) in the **background via the harness's Bash `run_in_background`** — the companion's own `--background` flag is a **no-op for `adversarial-review`** (it always runs foreground; only *task* subcommands branch on background) — owned by the main loop, never a subagent (the strand refutation applies to subagents); run **Pass A** (the Opus critic) and **Pass C** (an inline Opus soundness `Agent` call mirroring B's lens) as subagents, then **await Pass B's completion re-invoke before merging** (concurrent passes, barrier merge — design D3). State that `/xtty:cross-review` is **user-launched only** (the direct Bash call bypasses Codex's `disable-model-invocation` guardrail), and that **one launch authorizes the whole bounded run** (up to N rounds of paid Pass B) — a new review needs a new launch; spend is human-initiated **per run**, not per paid call (design D4).
- [ ] 2.2 Specify **portable location + the commit-range review substrate** for Pass B: resolve the companion by globbing `~/.claude/plugins/cache/openai-codex/codex/*/scripts/codex-companion.mjs`, picking the highest version by **semver/numeric** compare (not lexical — `1.0.10 > 1.0.6`); an absent companion is a **capability-absent degrade** per 2.5, not a fail-loud (`${CLAUDE_PLUGIN_ROOT}` is unset in a project command). Scope by **substrate, not focus text** (which does not restrict what Codex reviews): base **B** = the parent of the change's first commit; require a **clean working tree**; **checkpoint-commit each round's accepted fixes**; run `adversarial-review --base B` each round so `merge-base(B, HEAD)..HEAD` is always the whole change. **Assert before launch:** `git merge-base B HEAD` == `B`; the tree is clean; `git rev-list --merges B..HEAD` is empty; the first commit in `B..HEAD` is the change-introduction commit; and **every commit in `B..HEAD` carries verifiable per-commit ownership for the named change** — a **validated `OpenSpec-Change: <name>` trailer on each range commit** (the new convention this change introduces) or an explicit **immutable commit-hash manifest** — **regardless of branch location** (a per-change branch/worktree MAY be used for *isolation* but is **not** accepted as ownership *proof*: a branch can hold interleaved/arbitrary commits; path-based inference fails once implementation edits product files). **Fail closed** when any range commit lacks matching ownership metadata (or an unrelated commit is interleaved): decline and review an **isolated review branch of only the change's commits** (design D5/R6).
- [ ] 2.3 Specify the **common-schema union-with-consensus ledger**: **Pass C emits Codex's real `review-output` JSON schema** (top-level `verdict/summary/findings/next_steps`; per-finding `severity/title/body/file/line_start/line_end/confidence/recommendation` — **no `line`**, `additionalProperties:false`); merge findings tagged by source; flag a finding raised by **both** B and C as a **heuristic** two-model consensus signal — the same-finding match is a semantic judgment, not a mechanical join (design D3).
- [ ] 2.4 Specify the **terminating convergence loop**: each round adjudicate every finding as fix | dismiss-with-recorded-rationale, apply fixes, re-review; converged = zero unresolved findings from any pass (not identical output); bound at **N = 2 rounds**, then escalate the residual. On **every converged run**, surface the **full ledger including all dismissals + rationales** to the human (not only at the bound), so convergence-by-dismissal is visible; and **persist the run's verdict + adjudicated ledger + coverage label as the durable cross-review receipt** at `openspec/changes/<name>/cross-review-receipt.md` — the committed artifact the blocking pre-archive gate task and the archive precondition check (design D4/D7).
- [ ] 2.5 Specify the **3-way detectable degrade classifier** (the assumed `status → ready` probe does **not** exist): **(1) capability absent** — the companion glob matches nothing, or `codex` is absent from PATH → **single-model degrade** (run A + C, label the run single-model — A + C are same-family → no cross-model coverage), **not** a hard-fail: a fresh clone must not be blocked, and "never installed" vs "corrupted cache missing the companion" cannot be distinguished, so absent-companion defaults to degrade; **(2) present but broken** — a staged probe (`codex --version`, `codex app-server --help`, or `setup --json`, each under a timeout) exits nonzero, times out, or emits malformed JSON → **surface hard as a misconfiguration**, never a silent skip; **(3) auth absent, strictly identified** — skip Pass B **only** when **all** of `node.available===true && codex.available===true && auth.loggedIn===false && auth.source==="app-server" && auth.requiresOpenaiAuth===true` hold → label the run single-model; a **null/absent `auth.requiresOpenaiAuth` is INDETERMINATE → hard-fail** (the plugin normalizes an app-server connect failure and a genuine logout into the same shape — the strict predicate conservatively rejects some genuine logged-out states, stated honestly) (design D5/R4).
- [ ] 2.6 Confirm the command is committed (un-ignored) alongside the other `.claude/commands/xtty/` tooling (`.gitignore` allowlist covers it).
- [ ] 2.7 Verify by effect **and adversarial environment** (non-vacuous — against the real `setup` probe, not `status`): run `/xtty:cross-review` on a real in-scope change (tri-pass fires, ledger merges with a consensus flag, loop converges/escalates, full ledger surfaced); then exercise **all three classifier arms** — (a) **capability absent**: move the companion out of the glob path (and/or strip `codex` from PATH) → **single-model degrade, not a hard failure** (fresh-machine semantics); (b) **present but broken**: stub a staged probe to exit nonzero / hang past the timeout / emit malformed JSON → **hard error surfaced, not a silent skip**; (c) **strict auth absence**: all five predicate fields hold → skip labeled single-model, and a `setup` payload **lacking `auth.requiresOpenaiAuth`** → indeterminate → **hard-fail**. Make the semver-resolution check **non-vacuous**: create a **throwaway second version dir** under the plugin cache (or unit-test the resolver on a synthetic version list) so it actually proves `1.0.10 > 1.0.6` numeric ordering. Confirm the commit-range substrate assertions hold/decline correctly with several changes open, with an unrelated commit interleaved (→ isolated review branch), and with a range commit lacking ownership metadata (→ **fail closed**, even when the commits sit on a per-change branch — branch location is not ownership proof). Confirm the **receipt gate** by effect: a completed run persists `cross-review-receipt.md` (verdict + adjudicated ledger + coverage label), and the archive precondition **refuses** an in-scope change lacking one (design D4/D7/R10).
