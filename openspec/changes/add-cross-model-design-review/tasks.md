- [ ] 2.3 Specify the **common-schema union-with-consensus ledger**: **Pass C emits Codex's `review-output` JSON schema** (`severity/title/file/line/confidence`); merge findings tagged by source; flag a finding matched from **both** B and C (on file + claim) as a two-model consensus finding (design D3).

- [ ] 2.5 Specify the **detectable degrade path**: gate the Pass-B skip on Codex's own `status → ready` probe — **only `ready == false`** (unauth/headless/CI) → skip Pass B, run A + C, and **label the run single-model** (A + C are same-family → no cross-model coverage); **any other invocation failure** (unresolved path, module/spawn error) → **surface hard as a misconfiguration**, never a silent skip (design D5/R4).
