## Why

A single-model coherence pass is insufficient for substantive changes. Worked evidence from this session: the Opus `xtty-openspec-critic` returned **COHERENT** on `add-git-diff-wrap-toggle` while a GPT Codex adversarial review caught a real **config-ownership bug** (a base-only key modeled on `XttyProfile` instead of `XttyConfigSet`) *and* a too-shallow test plan. The two reviewers are complementary, not redundant: the critic checks **conformance** (rulebook + disk-drift) and never reads product source, while Codex checks **soundness** (approach/assumptions) and fact-checks claims against the real code. We want that cross-model check to be a **committed, repeatable practice** — an authority-free worker that runs the passes and surfaces one ledger, plus a **human** who reads it and gates archive — together with the critic hardened to fact-check a change's claims about *existing* code. (The exemplar config bug placed a *new* field on the wrong owner — a design-ownership soundness call — which the critic's code-accuracy pass deliberately cannot catch; that class stays a cross-model catch, which is *why* the cross-model passes carry the load.)

**What this change deliberately is *not*.** An earlier iteration of this proposal tried to make the cross-model review a **self-policing automated gate**: a model ran the review, wrote a "converged" receipt, and archive checked that receipt. Six rounds of its own cross-model review refuted that shape — every receipt/verdict/coverage-label is **model-authored**, so a mechanical check of one still trusts the model, and a model could dismiss every finding and self-certify. The irreducible lesson: **the human is the gate, not the model.** This change therefore splits cleanly into two layers with a hard rule between them — *the worker may be arbitrarily helpful but carries zero authority; the gate is authority-complete but has near-zero machinery and reads no model-authored artifact.*

## What Changes

- A committed **cross-model review worker** (`/xtty:cross-review <change>`, main-loop-driven) runs three review passes over a change: **Pass A** = the Opus critic (conformance, incl. the new code-accuracy Pass 4), **Pass B** = Codex adversarial-review (GPT soundness), **Pass C** = an *inline* Opus design-soundness pass (the diversity slice). It reviews a **deterministic best-effort commit range** (`base..HEAD`, base = the parent of the commit that added the change's `proposal.md` — a git rule, no ownership trailers) and **names that range in the ledger header** (base, HEAD, the reviewed file list, which passes ran on which effective models, and — verbatim — why any pass did not run). It merges the passes into one **source-tagged union ledger** with a **heuristic two-model consensus flag**, may iterate a **bounded** number of rounds (default 2, one launch authorizing the whole bounded run), and MAY persist the ledger as an **advisory, gate-inert** `cross-review-ledger.md`. **The worker's every output is advisory** — no verdict, no coverage label, no ledger, no consensus flag carries gate force or is read mechanically by any downstream step. Dismissals are *proposals* a human reads, never accepted states.
- A **human-attestation archive gate** (authority-complete, near-zero machinery). An in-scope change carries exactly **one blocking human-attestation task** in its `tasks.md` tail (after the `⟶ xtty-openspec-critic` task, before `⟶ archive-ritual`). It is **HUMAN-ONLY**: the model MUST STOP — it may not tick the task, and may not derive, compute, or fill in the attested value. The human runs a **committed deterministic digest script** themselves, reads the full final ledger, and only then ticks the task, recording the reviewed-state digest on the tick line. The **archive precondition** (step 0 of the hand-authored `⟶ archive-ritual`, for in-scope changes) **fails closed** unless all hold: (1) the human attestation exists and is well-formed; (2) the reviewed-state digest independently **recomputes** to the attested value; (3) the working tree/index is **clean**; (4) the **only** change since the reviewed state is the single human attestation **act** itself — no later commit altered a reviewed artifact or rewrote the attestation record (**exempt-by-act** staleness). The check reads **no model-authored artifact**: its inputs are the human's line, a git-computed digest from committed deterministic tooling (trust class of `git`/`openspec`, not runtime model judgment), and git ground truth.
- A **committed deterministic reviewed-state digest tool** (`scripts/`): refuses on a dirty tree, prints a digest of the reviewed range's diff **excluding exactly the two bookkeeping surfaces** (the advisory ledger + the tick/attestation surface in `tasks.md`) so recording the attestation cannot self-invalidate the digest. The **exempt-by-act** staleness rule (above) closes the residual hole a by-*path* exclusion leaves (a rewritten attestation record).
- **Model-family diversity** of the soundness passes, reported not enforced-as-a-gate: Pass B runs on the codex CLI's configured **GPT-family model** at an effort suitable to deep adversarial review; Passes A/C run on **Opus**. The worker **records the effective model + effort of each soundness pass in the ledger header** so a human can see whether the run was genuinely cross-family; a divergent local config produces an honestly-labeled header, not a blocked gate. The mechanism-neutral family-diversity invariant + effort floor live in the spec; the concrete pin (**`gpt-5.6-sol` / `xhigh`**) lives in `design.md` so it survives model-version drift.
- **Detectable, non-gating degradation.** When the external reviewer is unavailable (no companion resolvable by the version glob, or `codex` absent from PATH, or a logged-out workstation), the worker **skips Pass B, completes on the same-family passes, and says so plainly in the header** (which passes ran, which did not, and why). No degradation arm auto-satisfies or auto-blocks archive — degradation is information a human reads, never a gate input.
- **Pass C runs inline, not as a new standing agent** (the guide's anti-speculative-roster refutation); it emits Codex's real `review-output` schema (`body`/`line_start`/`line_end`/`recommendation`, no `line`) so B and C outputs are *comparable* — the two-model **consensus** is a **heuristic** confidence signal (the same-finding match is an irreducibly semantic judgment, not a mechanical join).
- The **critic gains a code-accuracy pass** (Pass 4): it fact-checks `design.md`/`tasks.md` claims about **existing** symbols against the actual source — an existing symbol absent/contradicted is a **BLOCKER**, a fuzzy/unlocatable claim is a **REVIEW**. It does **not** catch a misplaced *new* symbol (the exemplar bug's class — that stays a cross-model catch) and is **in-repo-only** (blind to external-dependency claims). The critic also gains a **REVIEW-severity check** that an in-scope change's tail carries the blocking human-attestation cross-review task (with the model-STOP wording), so the gate-task convention actually reaches `/opsx:propose` instead of living only in AGENTS.md prose. Its stamp bumps **v4**, and the launcher's stale delivery-check stamp is repaired **v1 → v4**.
- **AGENTS.md** documents the worker protocol, the mechanical **scope criterion**, the **human-attestation gate + the archive step-0 fail-closed precondition** (the four checks incl. exempt-by-act staleness + optional verify-commit-when-signed), and the "two reviewers cover different axes" framing; **`research/`** captures the finding — the complementary-axes evidence *and* this session's six-round refutation of the self-policing gate — with this session as the worked exemplar.

## Capabilities

### New Capabilities

- `cross-model-review`: a committed, **authority-free** worker that composes a conformance pass plus two soundness passes on **distinct model families** over a design-bearing change, reviews a deterministic best-effort commit range named in its ledger header, merges the passes into a union-with-heuristic-consensus advisory ledger, may iterate a bounded fix→re-review loop, and degrades detectably (reporting a skipped pass in the header) — **carrying zero gate semantics** — paired with a **human-attested, fail-closed archive gate**: an in-scope change carries one blocking human-attestation task ticked only by a direct human act recording the reviewed-state digest, and archive fails closed (reading no model-authored artifact) unless the attestation is present, its digest recomputes, the tree is clean, and the only post-review change is the attestation act itself.

### Modified Capabilities

- `coherence-review`: the `xtty-openspec-critic` single-change pass gains (a) a **design-claim code-accuracy** check — fact-checking a change's `design.md`/`tasks.md` claims about *existing* code, BLOCKER when a claimed existing symbol is absent/contradicted, REVIEW when fuzzy (it does **not** cover misplaced *new* symbols — that stays a cross-model catch — and checks **in-repo** symbols only, blind to external-dependency claims); and (b) a **REVIEW-severity gate-task presence** check — flagging an in-scope change whose `tasks.md` tail lacks the blocking human-attestation cross-review task (or whose task lacks the model-STOP/HUMAN-ONLY wording).

## Impact

- **New committed tooling**: `.claude/commands/xtty/cross-review.md` (the worker protocol) and a committed deterministic reviewed-state digest script under `scripts/`. The worker MAY persist an **advisory, gate-inert** `cross-review-ledger.md`; no file it writes is read mechanically by the archive gate.
- **`.claude/agents/xtty-openspec-critic.md`**: add the code-accuracy pass (Pass 4, existing-symbol, in-repo-only) + the gate-task presence check; bump agent `Definition: v4` and repair the launcher's stale delivery-check stamp **v1 → v4**.
- **`AGENTS.md`**: the worker protocol (passes, advisory union-with-heuristic-consensus ledger + header contract, bounded rounds, one-launch spend, detectable non-gating degradation), the **model-family diversity rule** (GPT-family Pass B vs Opus A/C; effective model+effort recorded in the header), the **mechanical scope criterion**, and — added to the hand-authored `⟶ archive-ritual` procedure — a **step-0 in-scope precondition** (the four fail-closed checks incl. exempt-by-act staleness + optional verify-commit-when-signed) plus the **human-attestation task template** (model-STOP/HUMAN-ONLY wording). The change-tail keeps `⟶ xtty-openspec-critic` as its own task and adds the one blocking human-attestation task; **no** auto-firing `⟶ xtty-cross-review` marker exists.
- **`research/03-analysis/`**: a new capture (`cross-model-design-review-*.md`) documenting the complementary-axes finding, this session's exemplar (critic COHERENT ↔ Codex caught the config bug), **and** the six-round refutation of the self-policing automated gate (why authority-free worker + human gate; why signing is optional-not-default), indexed in `research/README.md`.
- **External dependency**: the Codex plugin's companion script — Pass B runs on the codex CLI's configured GPT-family model (**`gpt-5.6-sol`**, pin in `design.md`), invoked via a **version-independent, version-ordered resolved path** (glob + numeric highest-version; an absent companion is a **detectable, non-gating skip**, not a hard failure — `${CLAUDE_PLUGIN_ROOT}` is unset in a project command) from the main loop, backgrounded via the **harness's Bash `run_in_background`** (the companion's own `--background` is a no-op for `adversarial-review`; never a subagent — `run_in_background` strands subagents). Focus text does **not** scope the review, so the worker reviews the deterministic `base..HEAD` range and names it in the header. **Human-initiated per run** (one launch authorizes the bounded N-round spend).
- **No product code and no `verification-harness` delta** — dev-workflow tooling (non-UI). Verified by inspection + live worker runs (a real in-scope change; a Codex-absent environment where the run completes and the header says so and nothing downstream reacts) + the by-effect archive-gate test: a real archive attempt on *this* change fails closed absent a fresh human attestation of the current reviewed-state digest.
- **Cost/latency**: tri-pass × up-to-N rounds is heavy, so it runs **once at pre-archive**, the mechanical gate skips purely-mechanical changes, and the detectable-skip path bounds the worst case.

## Dropped from the prior iteration

Deleted as unsound or over-built (each refuted by this change's own six rounds of cross-model review):

- The **`OpenSpec-Change:` per-commit ownership trailer** convention + immutable commit-hash manifests + per-commit ownership verification + isolated-review-branch fallback — the change could not even dogfood its own trailer rule on its already-landed history; replaced by the deterministic best-effort range named in the header (the human sees the range, no assertion chain to trust).
- The **model-authored `cross-review-receipt.md`** with a gate-checked converged verdict / coverage label — the banned converged-receipt-as-gate, the literal self-certification exploit; replaced by the human's tick line + the git-computed digest.
- The **convergence verdict as archive eligibility** — bounded iteration survives as worker behavior, but "converged" loses all gate force and dismissals become proposals.
- The **3-way degradation classifier's hard-fail/auto-satisfy arms** + the strict 5-field auth predicate — replaced by unconditional header reporting a human reads.
- The **coverage-label-as-gate-input** + effort-floor coverage audit — coverage is now human-read information in the header.
- **Not adopted:** a separate per-change countersignature *file* (re-grows a receipt-shaped artifact) and **mandatory signing** (kept only as a named optional strong form — it does not close the residual in a model-only apply loop and adds ceremony against the repo's $0 ethos).
